KOMPETENSI KEAHLIAN

💻 Pengembangan Perangkat Lunak & Gim (RPL)

Mencetak Software Engineer, Web Developer, dan Mobile App Creator yang profesional, inovatif, serta siap bersaing di industri teknologi global.

📖 Tentang Kompetensi Keahlian

Rekayasa Perangkat Lunak (RPL) merupakan salah satu jurusan komputasi yang sangat diminati di era transformasi digital saat ini. Siswa tidak hanya diajarkan cara menulis baris kode pemrograman (coding), melainkan juga diajarkan bagaimana mendesain arsitektur aplikasi, menganalisis kebutuhan pengguna, serta mengelola proyek pembuatan perangkat lunak berstandar industri.

Dengan pendekatan pembelajaran berbasis produk (Product-Based Learning) dan Teaching Factory, lulusan diarahkan untuk memiliki portofolio nyata dan siap bekerja di perusahaan teknologi maupun menjadi techpreneur.

🎯 Kompetensi Inti yang Dipelajari

🌐 Pemrograman Web

Pengembangan frontend & backend menggunakan HTML, CSS, JavaScript, serta Framework modern seperti React/Vue dan Laravel.

📱 Mobile App Development

Pembuatan aplikasi berbasis Android dan iOS menggunakan pemrograman berbasis objek dan framework lintas platform.

🗄️ Basis Data & Cloud

Perancangan struktur data (SQL/NoSQL), manajemen database, serta pengenalan infrastruktur cloud dasar.

🎨 UI/UX Design Fundamentals

Prinsip perancangan antarmuka aplikasi yang intuitif, ramah pengguna, dan estetik menggunakan tools industri.

💼 Peluang Karir Lulusan

Lulusan jurusan RPL memiliki cakupan prospek kerja yang sangat luas di industri teknologi:

👨‍💻 Web Developer 📲 Android/iOS Developer 🗃️ Database Administrator 🧪 Quality Assurance (QA) 🎨 UI/UX Designer 🚀 Tech Entrepreneur
